# Production Verification

Run gates in order and record evidence.

## Truth

Every metric, testimonial, logo, citation, capability, and outcome is supplied or verified. Mark placeholders visibly; never fill proof slots by invention.

## Argument preservation

Retain meaning, force, qualifications, and idiolect. Authorize substantive edits. Adapt layout to long content.

## Perception

L0–L4 appear in order. Failed lower layers block downstream approval. Requirements have observable verification.

## Accessibility

Check semantics, names, focus order, visible focus, keyboard use, contrast, reduced motion, non-color state, headings, landmarks, errors, and touch targets.

## Responsive and text resilience

Verify applicable widths among 320, 375, 414, 768, 1024, and 1440 CSS pixels; 200% zoom; long tokens; translations; no essential clipping; shrinkable grid/flex children; and table strategy.

## States

Interactive controls normally need default, focus-visible, active, and disabled. Fine pointers add hover. Asynchronous actions add loading; outcome-reporting adds error and success.

## Anti-slop, performance, and consistency

Check generic signals while preserving intentional deviations; then blocking assets, layout shift, latency, font/image strategy, tokens, type, spacing, icons, components, imagery, and voice.

## Bounded visual QA

One batched inspection, one batched correction, and at most one confirmation pass. Continue only when a named acceptance criterion remains false.
