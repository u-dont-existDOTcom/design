# Upstream Synthesis Evaluation — 2026-08-17

## Decision

Use an original canonical synthesis with pinned upstream relationships and optional narrow adapters. Do not merge or vendor the four source repositories wholesale.

## Why

The sources solve different layers:

- Impeccable is strongest as workflow and craft architecture.
- Perception-First Design is strongest as ordered diagnosis and ethical constraint.
- UI UX Pro Max is strongest as searchable design and stack intelligence.
- Hallmark is strongest as an adversarial generic-AI and factual-integrity gate.

Using all four independently would leave authority conflicts unresolved. Copying all four would create license, drift, duplication, and instruction-collision problems.

## Selected and rejected elements

### Impeccable

Selected: durable context, surface modes, refinement/redesign distinction, operation routing, bounded inspection.

Not canonicalized: its entire runtime, every command reference, and a default mandate for maximal visual ambition. The brief and surface mode decide the appropriate expressive intensity.

### Perception-First Design

Selected: L0–L4 ordering, requirement derivation, lower-layer precedence, ethical tests.

Not copied: canonical prose, scoring corpus, and trademarked naming. The synthesis uses original operational language and attribution.

### UI UX Pro Max

Selected: domain-separated search, master plus surface overrides, design dials, text resilience, stack-specific enrichment.

Not canonicalized: category-driven style selection before project diagnosis, complete datasets, or bundled font files. Search output remains subordinate evidence.

### Hallmark

Selected: structural anti-slop review, truth protection, token discipline, semantic state coverage, responsive verification, bounded self-critique.

Not canonicalized: universal aesthetic bans, silent theme rotation, or the requirement that every page inside one product have a different structural fingerprint. Intentional identity and within-product coherence take precedence.

## Resulting conflict rules

- Product truth and owner copy beat layout convenience.
- Lower perceptual layers beat upper-layer novelty.
- Established identity beats catalog ranking.
- Within-product consistency beats cross-project variety.
- Deliberate deviations survive when documented and verified.
- Clear valid winners continue automatically.
- Optional upstream failure degrades enrichment, not the canonical workflow.
